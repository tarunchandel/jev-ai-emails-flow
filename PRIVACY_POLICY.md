# Privacy Policy for Jev AI Corporate Actions Flow

**Last Updated:** October 2026

## 1. Overview
Jev AI Corporate Actions Flow ("the Application") provides workflow orchestration, classification, and review tools for corporate action notifications and financial email events.

## 2. Data Collection and Usage
- **Locally Processed Data:** The demo version processes corporate action event samples and simulated emails locally or through secured demo endpoints.
- **Personal Information:** The application does not collect, sell, or monetize user personal identity data, location, or contacts.
- **Google Play Services:** Standard diagnostics and crash reporting may be collected anonymously via Google Play Console to maintain stability and performance.

## 3. Network Communications & APIs
When live API mode is enabled, corporate actions requests are transmitted securely over HTTPS directly to authorized backend services or LLM decision engines (TypeSafe AI / Google Gemini) for document OCR and text synthesis.

## 4. Permissions
- **Internet:** Used for retrieving updates and communicating with optional demo endpoints.
- **Network State:** Used to detect offline vs online operational status.

## 5. Security
We take security seriously. All network communications utilize industry standard TLS encryption.
